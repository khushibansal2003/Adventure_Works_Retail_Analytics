# Adventure Works Retail Analytics

## Project Overview

This project analyzes Adventure Works retail sales data to identify sales performance, customer segments, and age-based customer behavior.

The solution uses Python for data cleaning and ETL, MySQL for centralized data storage and SQL analysis, and Power BI for business visualization.

---

## Technology Stack

- Python
- Pandas
- MySQL
- SQL
- Power BI
- Excel
- VS Code
